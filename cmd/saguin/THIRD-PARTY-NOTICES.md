# Third-party notices

Sagüin ships as one binary, so this travels inside it: `saguin --licenses`
prints this file. Every licence here is permissive and none constrains
Sagüin's own; what they ask for is attribution, and this is it.

Generated by `make notices` from `go list -deps ./cmd/saguin`, the set that
reaches the binary - asked of every platform the toolchain builds for and
merged, because the set is not the same on all of them - plus the MQTT
engine, which is a copy in the tree rather than a module and so is named
below by hand. Do not edit by hand.
